# A-B_Testing_Marketing_campaign
Deze repository bevat de resultaten van een A/B-testanalyse die de effectiviteit van reclamecampagnes onderzoekt. Het vergelijkt conversieratio’s tussen de 'ad' en 'psa' groepen met behulp van statistische tests zoals normaalverdelingstests, variantie-analyse en de Mann-Whitney U-test om de invloed van advertenties te beoordelen.
